# ShopLite - Лаборатори 1

## D2. Төслийн бүтэцтэй танилцах

1. lib/main.dart-д ямар классууд байна? Аль нь StatelessWidget, аль нь StatefulWidget вэ?

* ShopLiteApp: StatelessWidget (Аппын ерөнхий тохиргоо, theme-ийг тохируулна).

* ShopLiteHomePage: StatefulWidget (Сагсны барааны тооны төлөвийг удирдах класс).

* \_ShopLiteHomePageState: State (ShopLiteHomePage-ийн төлөв болон UI-ийг хариуцна).

2. pubspec.yaml-д ямар сангууд (dependencies, dev_dependencies) байна?

* dependencies:

  * flutter (Flutter фреймворкийн үндсэн сан)

  * cupertino_icons (iOS загварын икон сан)

* dev_dependencies:

  * flutter_test (Тест бичих сан)

  * flutter_lints (Кодын стандартын шалгалт хийх сан)

3. android/ хавтас юунд хэрэгтэй вэ? Та ихэвчлэн аль хавтсанд код бичих вэ?

* android/ хавтас нь аппыг Android дээр ажиллуулахад шаардлагатай тохиргоо болон файлуудыг агуулна.

* Кодыг ихэвчлэн lib/ хавтас дотор бичнэ.

## D4. Hot reload ба hot restart туршилт

| Өөрчлөлт | Hot reload (r) — юу болсон бэ? | Hot restart (R) — юу болсон бэ? | 
| ----- | ----- | ----- | 
| AppBar-ийн гарчгийг өөрчлөх | Гарчиг шууд өөрчлөгдөнө. Тоо хадгалагдана. | Апп дахин ачаалж гарчиг өөрчлөгдөнө. Тоо 0 болно. | 
| seed өнгийг солих | Аппын өнгө шууд солигдоно. Тоо хадгалагдана. | Апп дахин ачаалж өнгө солигдоно. Тоо 0 болно. | 
| int \_counter = 0; -> = 5 болгох | Одоогийн state хадгалагдах тул тоо өөрчлөгдөхгүй. | Restart хийхэд тооны анхны утга 5 болно. | 
| main() дотор print('start'); нэмэх | main() функц ажиллахгүй тул хэвлэгдэхгүй. | Restart хийхэд main() ажиллаж print хэвлэгдэнэ. | 

Асуултын хариулт:
Hot reload хийхэд тоолуурын утга хадгалагдсан. Учир нь Hot reload нь аппыг бүхэлд нь дахин эхлүүлэхгүйгээр зөвхөн кодын өөрчлөлтийг оруулдаг тул одоогийн widget-ийн state арилахгүй үлддэг.
